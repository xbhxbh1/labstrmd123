# Тестовий сервер (stub)

Окремий ASP.NET Core проєкт для модуля обліку палива. Не входить до збірки застосунку.

| Адреса | Призначення |
|--------|-------------|
| `http://localhost:5099/api/sync` | приймає записи черги офлайн-змін; при конфлікті зберігає новішу версію (за `UpdatedAt`) |
| `http://localhost:5099/api/auth/login` | вхід без шифрування (лише для відлагодження) |
| `https://localhost:5443/api/auth/login` | вхід по HTTPS, сертифікат закріплюється в застосунку |
| `https://localhost:5443/api/users` | перелік персоналу, лише для ролі `Accountant` (перевірка на сервері) |

Тестові облікові записи:

| Логін | Пароль | Роль |
|-------|--------|------|
| `operator` | `Operator#2024` | Оператор АЗС (`StationOperator`) |
| `accountant` | `Accountant#2024` | Бухгалтер (`Accountant`) |

## Запуск

```powershell
dotnet run --project stub/FuelErp.StubApi
```

Імітація атаки «людина посередині» (сервер показує сертифікат, якого застосунок не очікує):

```powershell
dotnet run --project stub/FuelErp.StubApi -- --rogue
```

## Сертифікат

`certs/stub-localhost.pfx` (пароль `stubpass`) - самопідписаний сертифікат лише для `localhost`.
Приватний ключ навмисно лежить у репозиторії, бо це навчальний тестовий сервер; у реальних
системах так робити не можна. SHA-256 відбиток сертифіката
(`103369995DF050FBE5C37D65716DC360F0D9925F7D8D5B790A81E98924E344D3`) зашитий у застосунку як «пін».
