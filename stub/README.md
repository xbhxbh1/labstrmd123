# Тестовий сервер (stub)

Окремий ASP.NET Core проєкт для лабораторних робіт 4-6. Не входить до збірки застосунку.

| Адреса | Призначення |
|--------|-------------|
| `http://localhost:5099/api/sync` | приймає записи черги синхронізації (лаб. 4) |
| `http://localhost:5099/api/auth/login` | вхід без шифрування (лише для відлагодження) |
| `https://localhost:5443/api/auth/login` | вхід по HTTPS, сертифікат закріплюється в застосунку (лаб. 6) |
| `https://localhost:5443/api/users` | список користувачів, лише для ролі `Administrator` (перевірка на сервері) |

Демо-користувачі: `admin` / `Admin#2024` (Administrator), `teacher` / `Teacher#2024` (Teacher).

## Запуск

```powershell
dotnet run --project stub/StudentCabinet.StubApi
```

Імітація атаки «людина посередині» (сервер показує сертифікат, якого застосунок не очікує):

```powershell
dotnet run --project stub/StudentCabinet.StubApi -- --rogue
```

## Сертифікат

`certs/stub-localhost.pfx` (пароль `stubpass`) - самопідписаний сертифікат лише для `localhost`.
Приватний ключ навмисно лежить у репозиторії, бо це навчальний тестовий сервер; у реальних
системах так робити не можна. SHA-256 відбиток сертифіката
(`103369995DF050FBE5C37D65716DC360F0D9925F7D8D5B790A81E98924E344D3`) зашитий у застосунку як «пін».
